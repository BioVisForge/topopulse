# Examples

The `examples/` directory covers basic static signaling, node dynamics, dynamic edges,
perturbations, treatment/control differences, fixed layouts, missing data, flux reversal, and a
larger synthetic graph. Each script writes into `artifacts/`.

`mapk_demo.py` generates the required MAPK SVG, GIF, and MP4. `control_vs_inhibitor.py` generates
synchronized condition outputs and the inhibitor-minus-control animation.
