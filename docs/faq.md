# FAQ

**Is TopoPulse a simulator?** No. It visualizes measurements or model outputs.

**Does an arrow prove causality?** No. It renders the supplied topology and semantics.

**Why strict alignment by default?** Silent dropping can produce plausible but incorrect figures.

**Why global normalization?** A stable scale supports honest comparison across animation frames.

**Is HTML interactive output available?** Not in v0.1. The renderer boundary is designed for a
future Cytoscape.js or Sigma.js backend without changing the graph/data model.
